#### FULLSTACK ENGINEER

I design fullstack apps for enterprise level architecture, from the database to the browser. I build Spring Boot microservices with an API Gateway, persist data using Spring Data JPA for both SQL and NoSQL, and secure microservices using JWT authentication. I create reactive apps with WebFlux and Angular Signals, implement SSR in Angular for improved SEO and speed, and stream real time data in Angular apps for live updates. I test and deploy full stack apps end to end with CI/CD pipelines. Beyond web apps, I also create reusable libraries, automation scripts, and cross-platform mobile apps that solve real problems and save teams time.
