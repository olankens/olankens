#### BACKEND DEVELOPER

I build and own the backend. My core stack is Spring Boot with Spring Data and Spring Security, delivering secure, transactional services built around clean architecture and solid domain modeling. I design REST APIs contract-first with OpenAPI, using Swagger UI to validate specs before a single line of implementation is written. On the frontend, I work with Angular and NgRx when the project demands it, but the backend is where I operate. I back everything with JUnit test suites plugged into GitHub Actions CI/CD pipelines, enforcing consistency from contract to deployment.
