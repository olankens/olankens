# AGENTS

## COMMIT MESSAGES

* Always add cspell words in lowercase, sorted, and one per line.
* Always classify README.md or .assets/ changes as the docs type.
* Always follow the commitlint configuration from package.json.
* Always keep every commit subject short, concise, and easy to scan.
* Always omit the scope when the project repository is not a monorepo.
* Always start every commit subject with a clear indicative verb.
* Always use the affected workspace or package name as the commit scope.
* Always use the word and before the final item in every enumeration.
* Never add co-authored-by trailers from any agentic tool or agent.
* Never classify shell script changes as the docs commitlint type.
* Never use the --no-verify flag for bypassing local commit hooks.
